日期：2026-10-29（America/New_York）。历史报告保留。本次按用户要求采用自动取消后续处理的方案。

## 行为

提交信息不足的指令后，仍先完成模型解析，再跳转到该指令的处理结果页面。状态保存为取消，运行记录结束为拒绝；原始指令和模型原因保留。

结果页优先展示模型给出的澄清/拒绝原因，缺失时使用说明字段；不展示检索范围、平台表达式、默认偏好、手动修改、重试解析或继续执行。唯一的当前任务操作是“重新下达新指令”，返回新指令输入页。

上述规则用于模型明确拒绝的 `unsupported` 结果。临时模型连接或配置错误仍保留既有失败重试，不混同为业务拒绝。正常检索计划仍可以修改范围，正常新邮件仍可以起草、对话修改、审核和发送。
