## 使用入口与边界

登录后：打开邮件 → 确认正文已读取 → 选择日期解释时区 → 分析邮件。相对日期以邮件发送时间（缺失时使用接收时间）为基准。结果页可查看证据、草稿及快照，顶部“候选事项”可比较多个来源。

原文逐字存在只能证明引用来源，不能保证模型语义理解完全正确。因此任务和回复保持待审核；日期推断、负责人不明、附件未分析、正文截断和来源冲突都会提示用户。

自动合并的范围是同一邮箱和会话内明确匹配的候选；跨会话及语义相似事项只提示，暂不提供人工合并按钮。比较范围为最近 100 个候选，不宣称实现全邮箱语义去重。

正文已有缓存时直接分析该缓存；需获取最新内容应先刷新邮件详情。失败后可从分析结果页继续。模型响应尚未保存时发生进程退出，重试仍可能产生额外 API 费用。

本次真实模型验收使用合成邮件；未代替用户逐封验证真实邮件理解质量。学校或个人邮箱的已连接状态由用户在开始阶段 2 前确认。
